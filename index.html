About

A developer and cybersecurity enthusiast focused on reverse engineering, malware analysis, and building security tools.

I created Jarscanner, a static malware analyzer designed to detect suspicious behavior in Java and Minecraft mod files. I enjoy researching how malicious software works, improving detection techniques, and turning that knowledge into practical, user-friendly tools.

Toolchain

  • Detect It Easy - packer and obfuscator identification
  • IDA Pro - native disassembly and decompilation
  • Recaf - JVM bytecode analysis and editing
  • Diobfuscator - JAR deobfuscation
  • dnSpy - .NET decompiler and debugger
  • pyinstxtractor - unpacking PyInstaller executables
  • 1shot - PyArmor deobfuscation
  • Burp Suite - web proxy, request tampering, API testing
  • Wireshark - traffic capture, C2 and exfil paths

Languages: Python, Java, JavaScript

Selected work

  • Jarscanner.org - static malware analysis platform for Java archives, with an emphasis on Minecraft mods and other JAR-based software. Inspects class files, manifests, embedded strings, URLs, webhooks, suspicious APIs and obfuscation patterns without executing the sample, and reports known malware families and potentially malicious functionality. Built with Java, TypeScript and Node.js.
  • Blog - long-form analysis of Java malware families: the loaders, stealers and RATs that circulate through Minecraft mods and cracked plugins. Each post walks a real sample from packing and obfuscation through to its exfiltration path and the indicators worth detecting on.
